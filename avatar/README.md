# Avatar options

Three monogram variants, 1000×1000 PNG. GitHub crops avatars to a circle, so
the initials sit well inside a safe centre area in all of them.

| File | Style |
|---|---|
| `avatar-1-gradient.png` | Teal gradient, serif monogram |
| `avatar-2-ink.png` | Near-black ground with a teal accent ring |
| `avatar-3-light.png` | Pale ground, deep teal serif — reads well on dark themes |

`avatar-options.png` is the three side by side, circle-cropped as GitHub renders
them. The `*-circle-preview.png` files are previews only.

**To use one:** [github.com/settings/profile](https://github.com/settings/profile)
→ click the avatar → Upload a photo. Upload the plain square file, not a
preview — GitHub does its own cropping.

GitHub has no API for avatars, so this step is manual by necessity.
